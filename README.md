# CvProject – Kişisel Portfolyo Projesi

Bu proje, **ASP.NET Core MVC** kullanılarak geliştirilmiş, admin panelli ve veritabanı destekli
bir **kişisel portfolyo web uygulamasıdır**.

## 🚀 Proje Amacı
- ASP.NET Core MVC mimarisini öğrenmek
- Entity Framework Core (Code First) ile CRUD işlemleri yapmak
- Admin Panel + Public (Vitrin) yapısını gerçek projeye yakın şekilde kurmak

## 🛠 Kullanılan Teknolojiler
- ASP.NET Core MVC
- C#
- Entity Framework Core (Code First)
- MS SQL Server
- HTML, CSS
- Bootstrap
- TailwindCSS (Admin Panel)

## 📌 Özellikler
### 🔹 Vitrin (Public)
- Ana Sayfa
- Hakkımda
- Deneyimler
- Yetenekler
- Projeler
- İletişim Formu

### 🔹 Admin Panel
- Dashboard (Mesaj istatistikleri)
- Hakkımda yönetimi
- Deneyim yönetimi
- Yetenek yönetimi
- Proje yönetimi
- Gelen mesajları görüntüleme
